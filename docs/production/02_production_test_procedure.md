# 생산 테스트 절차서 (Production Test Procedure)

> GPS RTK Rover 보드 생산 라인 테스트 절차

**문서 버전**: v1.0
**최종 수정**: 2024-12-15
**적용 제품**: GPS_RTK_ROVER (GRR-100)

---

## 1. 개요

이 문서는 생산 라인에서 GPS RTK Rover 보드를 테스트하는 절차를 설명합니다.
작업자는 이 문서를 따라 보드를 테스트하고 합격/불합격을 판정합니다.

### 1.1 테스트 목적

- 제조 공정의 불량 조기 발견
- 출하 전 품질 보증
- 불량률 추적 및 개선

### 1.2 소요 시간

| 단계 | 예상 시간 |
|------|----------|
| 준비 | 30초 |
| 플래싱 | 30초 |
| 자동 테스트 | 30초 |
| 결과 확인 | 10초 |
| **총 소요** | **약 2분** |

## 5. 문제 해결

### E-01: 전원 LED 안 켜짐

**증상:** 전원 인가 후 전원 LED가 점등되지 않음

**원인 및 조치:**
1. 전원 공급기 설정 확인 (12V, 1A)
2. 전원 케이블 연결 확인
3. 보드 방향 확인
4. 위 모두 정상이면 → 전원부 불량, 불량 처리

### E-02: ST-Link 연결 실패

**증상:** "Cannot connect to target" 오류

**원인 및 조치:**
1. ST-Link USB 연결 확인
2. 보드 고정 상태 확인 (포고핀 접촉)
3. ST-Link 드라이버 확인
4. ST-Link 교체 테스트

### E-03: 플래싱 실패

**증상:** "Programming failed" 오류

**원인 및 조치:**
1. 전원 상태 확인
2. ST-Link 연결 확인
3. 펌웨어 파일 확인
4. 재시도 (3회까지)
5. 계속 실패 시 → MCU 불량 의심

### E-04: EC25 테스트 실패

**증상:** "EC25 no response" 또는 타임아웃

**원인 및 조치:**
1. EC25 모듈 납땜 상태 확인
2. EC25 전원 (VBAT) 확인 (3.4~4.2V)
3. UART 연결 확인 (TX/RX)
4. 재작업 또는 모듈 교체

### E-05: LoRa 테스트 실패

**증상:** "RAK3172 no response"

**원인 및 조치:**
1. RAK3172 모듈 납땜 상태 확인
2. 3.3V 전원 확인
3. UART 연결 확인
4. 재작업 또는 모듈 교체

### E-06: GPS 테스트 실패

**증상:** "No NMEA data" 또는 타임아웃

**원인 및 조치:**
1. GPS 모듈 납땜 상태 확인
2. GPS 안테나 연결 확인 (테스트 시)
3. UART 연결 확인
4. 타임아웃 시간 확인 (실내에서는 더 오래 걸림)
