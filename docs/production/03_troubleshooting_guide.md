## 1. 전원 관련 문제

### 1.1 전원 LED가 켜지지 않음

**증상**
- 전원 인가 후 전원 LED(녹색)가 점등되지 않음
- 보드가 전혀 동작하지 않음

**원인 및 해결**

| 순서 | 확인 사항 | 예상 원인 | 해결 방법 |
|------|----------|----------|----------|
| 1 | 전원 공급기 출력 확인 | 전원 공급 안 됨 | 12V 출력 확인 |
| 2 | 전원 케이블 연결 | 케이블 불량/미연결 | 케이블 교체/재연결 |
| 3 | 커넥터 극성 | 역극성 연결 | 극성 확인 후 재연결 |
| 4 | 입력 퓨즈 (F1) | 퓨즈 단선 | 퓨즈 교체 |
| 5 | 입력 다이오드 (D1) | 역극성 보호 동작 | 극성 확인 |
| 6 | DC-DC 컨버터 | 전원부 불량 | 재작업/보드 교체 |

**측정 포인트**
```
┌─────────────────────────────────────┐
│           전원부 회로도              │
├─────────────────────────────────────┤
│                                     │
│  VIN ──[F1]──[D1]──┬──[DC-DC]──3.3V │
│                    │                │
│  GND ──────────────┴────────────GND │
│                                     │
│  확인 포인트:                        │
│  TP1: VIN (10.5~14.5V)              │
│  TP2: GND                           │
│  TP3: DC-DC 입력 (퓨즈 후단)         │
│  TP4: 3.3V 출력                      │
│                                     │
└─────────────────────────────────────┘
```

---

### 1.2 3.3V 전압 이상

**증상**
- 3.3V 레일 전압이 규격(3.135V~3.465V)을 벗어남
- 보드 동작 불안정

**원인 및 해결**

| 전압 상태 | 예상 원인 | 해결 방법 |
|----------|----------|----------|
| 0V | DC-DC 컨버터 불량 | U1 교체 |
| 낮음 (<3.0V) | 과부하/쇼트 | 쇼트 포인트 확인 |
| 높음 (>3.6V) | DC-DC 피드백 불량 | R1, R2 확인 |
| 불안정 | 커패시터 불량 | C1, C2 교체 |

---

### 1.3 소비 전류 과다

**증상**
- 대기 전류가 100mA 이상
- 보드가 발열

**원인 및 해결**

| 순서 | 확인 사항 | 해결 방법 |
|------|----------|----------|
| 1 | 쇼트 포인트 확인 | 육안 검사, 열화상 카메라 |
| 2 | EC25 모듈 | 모듈 분리 후 전류 측정 |
| 3 | GPS 모듈 | 모듈 분리 후 전류 측정 |
| 4 | MCU 상태 | 펌웨어 재플래싱 |

## 2. 플래싱 문제

### 2.1 ST-Link 연결 실패

**증상**
```
Error: Cannot connect to target!
Error: Target not found
```

**원인 및 해결**

| 순서 | 확인 사항 | 해결 방법 |
|------|----------|----------|
| 1 | ST-Link USB 연결 | USB 케이블 재연결 |
| 2 | ST-Link 드라이버 | 드라이버 재설치 |
| 3 | SWD 핀 연결 | SWDIO, SWCLK, GND 확인 |
| 4 | 보드 전원 | 12V 전원 인가 확인 |
| 5 | MCU 상태 | BOOT0 핀 확인 (GND) |
| 6 | MCU 불량 | 보드 교체 |

**SWD 핀맵**
```
ST-Link          보드
─────────────────────
 SWDIO   ───────  PA13
 SWCLK   ───────  PA14
 GND     ───────  GND
 3.3V    ─ (선택) ─ VDD
 NRST    ─ (선택) ─ NRST
```

---

### 2.2 플래싱 중 에러

**증상**
```
Error: Flash programming failed
Error: Verification failed
```

**원인 및 해결**

| 에러 메시지 | 원인 | 해결 방법 |
|------------|------|----------|
| Programming failed | Flash 쓰기 실패 | 전원 안정성 확인, 재시도 |
| Verification failed | 데이터 불일치 | Flash 전체 소거 후 재시도 |
| Timeout | 통신 불안정 | 케이블 확인, 속도 낮춤 |
| Read-out protection | 보호 설정됨 | Option bytes 초기화 |

**해결 절차**
```bash
# 1. Flash 전체 소거
STM32_Programmer_CLI -c port=SWD -e all

# 2. Option bytes 초기화 (필요시)
STM32_Programmer_CLI -c port=SWD -ob RDP=0xAA

# 3. 재플래싱
STM32_Programmer_CLI -c port=SWD -w firmware.bin 0x08000000 -v
```

## 3. LTE (EC25) 문제

### 3.1 EC25 응답 없음

**증상**
- AT 명령에 응답 없음
- 테스트 결과: "EC25 no response"

**원인 및 해결**

```
┌─────────────────────────────────────────────────────────────┐
│                    EC25 문제 해결 순서도                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    EC25 응답 없음                           │
│                         │                                   │
│                         ▼                                   │
│                ┌────────────────┐                          │
│                │ 전원 확인      │                          │
│                │ (VBAT 3.4~4.2V)│                          │
│                └───────┬────────┘                          │
│                        │                                   │
│            ┌───────────┴───────────┐                       │
│            │                       │                       │
│         정상                     비정상                     │
│            │                       │                       │
│            ▼                       ▼                       │
│    ┌───────────────┐      ┌───────────────┐               │
│    │ UART 연결 확인 │      │ 전원부 점검   │               │
│    │ (TX/RX 핀)    │      │ LDO 출력 확인 │               │
│    └───────┬───────┘      └───────────────┘               │
│            │                                               │
│   ┌────────┴────────┐                                     │
│   │                 │                                     │
│ 정상              비정상                                   │
│   │                 │                                     │
│   ▼                 ▼                                     │
│ ┌─────────┐   ┌─────────────┐                            │
│ │PWRKEY   │   │ 납땜 재작업  │                            │
│ │신호 확인│   │ (TX/RX 핀)  │                            │
│ └────┬────┘   └─────────────┘                            │
│      │                                                    │
│      ▼                                                    │
│ ┌─────────────┐                                          │
│ │ EC25 모듈   │                                          │
│ │ 불량 → 교체 │                                          │
│ └─────────────┘                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**확인 포인트**

| 항목 | 핀/테스트포인트 | 정상값 | 확인 방법 |
|------|----------------|--------|----------|
| VBAT | TP_VBAT | 3.4~4.2V | 멀티미터 |
| STATUS | EC25_STATUS | High=ON | 오실로스코프 |
| PWRKEY | EC25_PWRKEY | 500ms Low | 부팅 시 확인 |
| TX | USART1_TX | UART 신호 | 오실로스코프 |
| RX | USART1_RX | UART 신호 | 오실로스코프 |

## 4. LoRa (RAK3172) 문제

### 4.1 RAK3172 응답 없음

**증상**
- AT 명령에 응답 없음
- 테스트 결과: "RAK3172 no response"

**원인 및 해결**

| 순서 | 확인 사항 | 정상값 | 해결 방법 |
|------|----------|--------|----------|
| 1 | 3.3V 전원 | 3.3V ±5% | 전원부 확인 |
| 2 | UART TX/RX | 신호 있음 | 납땜 확인 |
| 3 | RESET 핀 | High | 리셋 회로 확인 |
| 4 | 모듈 상태 | - | 모듈 교체 |

**UART 설정 확인**
```
Baudrate: 115200
Data bits: 8
Parity: None
Stop bits: 1
```

---

### 4.2 LoRa 통신 거리 짧음

**증상**
- 기대 거리(10km) 보다 짧은 통신 거리
- 패킷 손실률 높음

**원인 및 해결**

| 원인 | 확인 방법 | 해결 방법 |
|------|----------|----------|
| 안테나 불량 | SWR 측정 | 안테나 교체 |
| 안테나 미연결 | 육안 확인 | 재연결 |
| 출력 설정 | AT+TXP=? | 출력 증가 |
| SF 설정 | AT+SF=? | SF 값 증가 (SF9 권장) |
| 주파수 | AT+FREQ=? | 920.9MHz 확인 |
| 장애물 | 현장 확인 | 안테나 위치 조정 |

**권장 설정**
```
AT+NWM=0          # P2P 모드
AT+PFREQ=920900000 # 920.9 MHz
AT+PSF=9          # Spreading Factor 9
AT+PBW=0          # 125 kHz
AT+PCR=0          # 4/5
AT+PPL=8          # Preamble 8
AT+PTP=14         # TX Power 14 dBm
```

## 5. GPS 문제

### 5.1 GPS 데이터 수신 안 됨

**증상**
- NMEA 데이터가 출력되지 않음
- 테스트 결과: "No NMEA data"

**원인 및 해결**

| 순서 | 확인 사항 | 해결 방법 |
|------|----------|----------|
| 1 | GPS 모듈 전원 | 3.3V 확인 |
| 2 | UART 연결 | TX/RX 납땜 확인 |
| 3 | GPS 안테나 | 안테나 연결 확인 |
| 4 | 실내/실외 | 실외 테스트 (하늘 보이는 곳) |
| 5 | 모듈 불량 | 모듈 교체 |

**참고: Cold Start vs Hot Start**
```
Cold Start: 첫 위성 획득까지 30~60초
Warm Start: 이전 정보 있으면 10~30초
Hot Start:  최근 정보 있으면 1~5초

→ 테스트 시 충분한 대기 시간 필요 (실내: 더 오래)
```

---

### 5.2 GPS 정확도 낮음

**증상**
- 위치 오차가 큼 (> 10m)
- RTK Fix 안 됨

**원인 및 해결**

| 원인 | 확인 방법 | 해결 방법 |
|------|----------|----------|
| 위성 수 부족 | $GPGGA 확인 | 안테나 위치 조정 |
| 안테나 불량 | 다른 안테나 테스트 | 안테나 교체 |
| RTCM 미수신 | NTRIP 연결 확인 | 보정 데이터 확인 |
| 기지국 거리 | 기지국 위치 확인 | 가까운 기지국 사용 |

## 7. RS485 문제

### 7.1 RS485 통신 안 됨

**증상**
- 루프백 테스트 실패
- 외부 장치와 통신 안 됨

**원인 및 해결**

| 순서 | 확인 사항 | 해결 방법 |
|------|----------|----------|
| 1 | 트랜시버 전원 | 3.3V/5V 확인 |
| 2 | A/B 연결 | 극성 확인 |
| 3 | 종단 저항 | 120Ω 확인 |
| 4 | DE/RE 제어 | 타이밍 확인 |
| 5 | 트랜시버 불량 | IC 교체 |

**RS485 배선**
```
장치 A                     장치 B
  A ─────────────────────── A
  B ─────────────────────── B
 GND ────────────────────── GND

양쪽 끝에 120Ω 종단 저항 필요
```
