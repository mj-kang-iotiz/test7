# QC 체크리스트 (Quality Control Checklist)

> GPS RTK Rover 보드 품질 검사 체크리스트

**문서 버전**: v1.0
**최종 수정**: 2024-12-15
**적용 제품**: GPS_RTK_ROVER (GRR-100)

---

## 1. 문서 개요

이 문서는 GPS RTK Rover 보드의 품질 검사(QC) 항목과 합격 기준을 정의합니다.
모든 보드는 출하 전 이 체크리스트의 검사를 통과해야 합니다.

### 1.1 검사 단계

```
PCB 제조 → IQC → SMT 실장 → AOI → ICT → 펌웨어 플래싱 → 기능 테스트 → OQC → 포장
                                                            ↑
                                                      이 체크리스트
```

### 1.2 검사 장비

| 장비 | 용도 | 필수 여부 |
|------|------|----------|
| 멀티미터 | 전압/저항 측정 | 필수 |
| ST-Link | 펌웨어 플래싱 | 필수 |
| 전원 공급기 | 12V 전원 공급 | 필수 |
| USB-UART 컨버터 | 로그 확인 | 권장 |
| 루프백 케이블 | RS485 테스트 | 권장 |

## 7. 불량 처리 절차

### 7.1 불량 유형별 처리

| 불량 유형 | 처리 방법 | 담당 |
|----------|----------|------|
| 외관 불량 (경미) | 양품 처리 | QC |
| 외관 불량 (심각) | 재작업 요청 | QC → 생산 |
| 전원 불량 | 재작업 또는 폐기 | QC → 엔지니어 |
| 기능 불량 | 원인 분석 후 재작업 | QC → 엔지니어 |
| 모듈 불량 | 모듈 교체 | 생산 |

### 7.2 불량 기록

불량 발생 시 아래 정보를 기록합니다:

- 시리얼 번호
- 불량 유형
- 발생 일시
- 조치 내용
- 담당자

## 8. 부록

### 8.1 펌웨어 버전 확인 방법

UART (115200bps)로 연결 후:
```
AT+VERSION
+VERSION:v1.0.0,Dec 15 2024,abc1234
OK
```

### 8.2 시리얼 번호 확인 방법

```
AT+SERIAL?
+SERIAL:GRR-241215-0001
OK
```

### 8.3 테스트 모드 진입 방법

1. 전원 OFF
2. TEST 버튼 누른 상태에서 전원 ON
3. LED 점멸 확인
4. 테스트 자동 진행
