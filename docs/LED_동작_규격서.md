# IoTiz - 구구시스템 RTK GPS 디바이스 LED 동작 규격

---

## 1. LED 하드웨어 구성

### 1.1 LED 배치

| LED ID | 기능 | GPIO 핀 |
|--------|------|---------|
| LED 1 | GSM/NTRIP 상태 표시 | GPIOC 1-2 (R-G) |
| LED 2 | GPS 상태 표시 | GPIOC 3-4 (R-G) |
| LED 3 | LoRa 상태 표시 | GPIOB 13-14 (R-G) |

### 1.2 LED 색상 정의

| 색상 | 값 | GPIO 상태 | 일반적 의미 |
|------|----|-----------| ------------|
| OFF (꺼짐) | 0 | R=HIGH, G=HIGH | 기능 비활성화 |
| RED (빨강) | 1 | R=LOW, G=HIGH | 에러/실패/연결 끊김 |
| YELLOW (노랑) | 2 | R=LOW, G=LOW | 대기/진행 중/중간 상태 |
| GREEN (초록) | 3 | R=HIGH, G=LOW | 정상/성공/연결됨 |

### 1.3 점멸 패턴

| 패턴 | 설명 | 용도 |
|------|------|------|
| 점등 (Solid) | 계속 켜져 있음 | 상태 유지 표시 |
| 점멸 (Blink) | 주기적으로 깜빡임 (~1Hz) | 데이터 송수신/동작 중 표시 |

## 2. BASE 모드 LED 동작

### 2.1 LED 1 - GSM/NTRIP 상태 (BASE)

#### 2.1.1 수동좌표 사용 설정 시 (NTRIP 미사용)

| 단계 | 상태 | LED 색상 | 점멸 | 설명 |
|------|------|----------|------|------|
| 1 | 초기화 | OFF | - | NTRIP 기능 비활성화 |

> **참고:** 수동좌표 모드에서는 NTRIP을 사용하지 않으므로 LED 1은 항상 꺼져 있습니다.

#### 2.1.2 수동좌표 미사용 설정 시 (NTRIP 사용 - Auto Averaging)

| 단계 | 상태 | LED 색상 | 점멸 | 설명 |
|------|------|----------|------|------|
| 1 | 디바이스 구동 | RED | 점등 | GSM 모듈 초기화 시작 |
| 2 | GSM 초기화 중 | RED | 점멸 | GSM 데이터 수신마다 토글 |
| 3 | NTRIP 연결 시도 | YELLOW | 점등 | TCP 소켓 연결 시도 중 |
| 4a | 연결 성공 | GREEN | 점등 | NTRIP 서버 연결 완료 |
| 4b | 연결 실패 | RED | 점등 | TCP 연결 실패, 재시도 대기 |
| 5 | 데이터 수신 중 | GREEN | 점등 | 보정 데이터 정상 수신 |
| 6 | 데이터 타임아웃 (1~2회) | YELLOW | 점등 | 데이터 수신 대기 중 |
| 7 | 데이터 타임아웃 (3회) | RED | 점등 | 재연결 시도 시작 |
| 8 | 재연결 성공 | GREEN | 점등 | 연결 복구 완료 |
| 9 | Averaging 완료 후 | OFF | - | NTRIP 종료, Base Mode 전환 |

### 2.2 LED 2 - GPS 상태 (BASE)

| GPS Fix 상태 | Fix 값 | LED 색상 | 점멸 | 설명 |
|--------------|--------|----------|------|------|
| No Fix | 0 | RED | 점멸 | GPS 신호 없음 |
| GPS Fix (SPS) | 1 | RED | 점멸 | 단독 측위 |
| DGPS | 2 | RED | 점멸 | 차분 GPS |
| RTK Fixed | 4 | **YELLOW** | 점멸 | RTK 고정해 (⚠️ BASE는 YELLOW) |
| RTK Float | 5 | YELLOW | 점멸 | RTK 부동해 |
| Manual Position | - | GREEN | 점멸 | 수동 좌표 설정됨 |
| HDOP ≥ 99.0 | - | GREEN | 점멸 | Averaging 완료 상태 |

> **중요:** BASE 모드에서는 RTK Fixed 상태여도 LED가 **YELLOW**입니다.
> 이는 ROVER와 구분하기 위한 의도적인 설계입니다.

## 5. BLE 상태 알림 (Base Notify)

### 5.1 수동좌표 미사용 설정 시 (Auto Averaging)

디바이스 구동 후 BLE를 통해 주기적으로 상태를 전송합니다.

| 단계 | 알림 내용 | 형식 | 설명 |
|------|-----------|------|------|
| 1 | NTRIP 접속 시도 | `"x,x\n"` | 10초마다 전송 |
| | | 첫번째 숫자: 접속 상태 | 0=접속중, 1=성공, 2=실패 |
| | | 두번째 숫자: GPS Fix | GPS Fix Quality 값 |
| 2 | Averaging 시작 | `"Start Averaging x%"` | Fix Mode 진입 후 시작 (50초 소요) |
| 3 | Averaging 완료 | `"Start Base use ntrip"` | Base Mode 동작 시작 |

#### 5.1.1 접속 상태 값과 LED 1 색상 매핑

| 접속 상태 값 | 의미 | LED 1 색상 |
|--------------|------|------------|
| 0 | 접속 중 | YELLOW |
| 1 | 접속 성공 | GREEN |
| 2 | 접속 실패/없음 | RED 또는 OFF |

### 5.2 수동좌표 사용 설정 시

| 단계 | 알림 내용 | 설명 |
|------|-----------|------|
| 1 | `"Start Base manual"` | Base Mode 수동 시작 |
| 2 | 설정 변경 필요 시 | RS 명령어로 디바이스 재시작 |

## 7. 트러블슈팅 가이드

### 7.1 LED 상태별 문제 진단

| LED 상태 | 가능한 문제 | 해결 방법 |
|----------|-------------|-----------|
| LED 1: RED 지속 | NTRIP 서버 연결 실패 | 서버 주소/포트 확인, 네트워크 상태 점검 |
| LED 1: YELLOW 지속 | 연결 시도 중 멈춤 | GSM 모듈 상태 확인, SIM 카드 점검 |
| LED 2: RED 점멸 지속 | GPS 신호 불량 | 안테나 위치 조정, 개활지로 이동 |
| LED 2: YELLOW 점멸 지속 | RTK Float 상태 유지 | 보정 데이터 수신 확인, 기선 거리 점검 |
| LED 3: RED 점등 | LoRa 초기화 실패 | 하드웨어 점검, 전원 재시작 |
| LED 3: 점멸 없음 | 데이터 송수신 없음 | LoRa 주파수/채널 설정 확인 |

### 7.2 정상 동작 시 예상 LED 패턴

#### BASE 정상 동작 (NTRIP 사용 + RTK Fixed)
```
LED 1: GREEN (점등)     - NTRIP 연결됨
LED 2: YELLOW (점멸)    - RTK Fixed (BASE는 YELLOW)
LED 3: GREEN (점멸)     - RTCM 송신 중
```

#### ROVER 정상 동작 (RTK Fixed)
```
LED 1: GREEN (점등)     - NTRIP 연결됨 (사용 시)
LED 2: GREEN (점멸)     - RTK Fixed (ROVER는 GREEN)
LED 3: GREEN (점멸)     - RTCM 수신 중
```
